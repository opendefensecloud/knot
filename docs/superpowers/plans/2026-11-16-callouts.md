# Callout Boxes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Five GitHub/GitLab callout kinds (note, tip, important, warning, caution) with an optional title, as attributes on `blockquote`, round-tripping through Markdown and shown in the editor, on public pages and in DOCX/ODT.

**Architecture:** `blockquote` gets `kind` and `title` attributes (schema-generated for Rust and TS). One Rust module `knot_markdown::callout` owns the kinds, the Markdown marker line and the import pre-pass; Markdown export, the importer, `knot-export` and the public page use it. The web side has one module `callouts.ts` (kinds, labels, icons) used by a blockquote node view, the toolbar menu, an input rule and paste.

**Tech Stack:** Rust (yrs, pulldown-cmark 0.13, ammonia), TypeScript/React, Tiptap 3 + y-tiptap, vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-16-callouts-design.md`

## Global Constraints

- Kinds exactly `note|tip|important|warning|caution`; labels `Note`, `Tip`, `Important`, `Warning`, `Caution`; any other `kind` value is treated as a plain quote everywhere.
- `title`: plain text, trimmed, newlines → spaces; empty = no title.
- Markdown: untitled `> [!WARNING]` (upper case, own line); titled `> [!warning] Title` (lower case). Import is case-insensitive for both.
- Box content must never be lost (old clients, rollback, round trip); only exception: a box in a table cell exports as its text.
- Look = mockup style C: header `color-mix(in oklab, hue 14%, surface)`, title `color-mix(in oklab, hue 80%, fg)`, border `color-mix(in oklab, hue 45%, surface)`; hues light/dark: note `#0969DA`/`#4493F8`, tip `#1A7F37`/`#3FB950`, important `#8250DF`/`#AB7DF8`, warning `#9A6700`/`#D29922`, caution `#CF222E`/`#F85149`. Contrast per `tokens.css` (body 7:1, muted 4.5:1).
- Icons (lucide): `Info`, `Lightbulb`, `MessageSquareWarning`, `TriangleAlert`, `OctagonAlert`.
- `crates/knot-markdown/src/legacy/` stays untouched.
- Build: `RUSTFLAGS="-D warnings -A deprecated"`, `cargo test` (no nextest), `set -o pipefail` with `| tail`.
- Marco's rule: each task's failing tests are shown to Marco and discussed **before** implementing (⏸ in each task).
- Branch `feat/callouts` (stacked on `feat/table-of-contents`); Conventional Commits.

## Review Focus

1. A plain quote whose first line is literally `[!NOTE]` (user text) must stay a plain quote after export → import (escaped). → Task 2 test `plain_quote_starting_with_marker_text_stays_a_quote`.
2. A fenced code block containing `> [!WARNING] x` must stay code. → Task 2 test `marker_in_code_block_is_code`.
3. An old client (schema without `kind`/`title`) opening and editing a box keeps all text. → Task 5 test `old client keeps the text of a box`.
4. Title with Markdown-significant text (`*a*`, `<b>`, `]`) survives export → import verbatim and is escaped on the public page. → Task 2 `title_with_markdown_characters_round_trips`, Task 4 `callout_title_is_escaped`.
5. Unknown `kind` value in the document (e.g. `"danger"`) renders and exports as a plain quote, no crash. → Task 2 `unknown_kind_exports_as_plain_quote`, Task 5 `unknown kind renders as plain quote`.

### Task 2: Markdown export and import

**Files:**
- Modify: `crates/knot-markdown/src/to_markdown.rs` (`write_quote` ~769: marker line first), `crates/knot-markdown/src/callout.rs` (marker + pre-pass), `crates/knot-markdown/src/from_markdown.rs` (options ~91, `Tag::BlockQuote` ~151)
- Test: `crates/knot-markdown/tests/callouts.rs`

**Interfaces:**
- Consumes: Task 1 `CalloutKind`, `callout_of`.
- Produces: `pub fn marker_line(kind: CalloutKind, title: Option<&str>) -> String` (`[!WARNING]` / `[!warning] Title`, title escaped); `pub struct CalloutMarks { pub src: Cow<str>, pub titles: Vec<Option<String>> }` and `pub fn mark_callouts(src: &str) -> CalloutMarks`.
- Import mechanism (decided): `mark_callouts` walks pulldown-cmark's offset events (same options as the importer, plus `ENABLE_GFM`); for every `Start(BlockQuote(_))` whose first line in `src` is `[!kind] title` (kind valid, title non-empty) it rewrites that line to `[!KIND]` and records the unescaped title; titles are listed in the order the importer will see `Tag::BlockQuote(Some(_))`. The importer enables `Options::ENABLE_GFM`, runs `mark_callouts` after `mark_toc_markers`, and on `Tag::BlockQuote(Some(kind))` pushes a blockquote with `kind` and the next recorded title (`None` for untitled ones — record `None` for those too so order stays aligned). An empty box gets one empty paragraph.
- Escaping (decided): a plain quote whose first content line starts with `[!` is written with `\[!`; a title escapes `\`, `*`, `_`, `` ` ``, `[`, `]`, `<`, `&` with a backslash.
